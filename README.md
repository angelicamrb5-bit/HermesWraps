# HermesWraps

Website work for Hermes Wraps.

- `brand/hermes-wraps-color-guide.pdf`: brand color guide (palette, rules, web tokens)
- `brand/tokens.css`: CSS color variables for the site
- `brand/tools/build_brand_guide.py`: regenerates both from one palette (`python3 brand/tools/build_brand_guide.py`)
- `CLAUDE.md`: guardrails every change must follow
