# Inspiration - reference designs the client likes

Screenshots of pages the client likes live in this folder. They show the **quality level and feel** the Hermes Wraps experience should reach. They are never templates. Translate, don't copy: Hermes Wraps must not end up with the same gadgets as other companies.

## How to add a reference

1. Save the screenshot here as `NN-short-name.png` (or `.jpg`/`.webp`), e.g. `01-clean-hero.png`. Full-page or section crops are both fine.
2. Add an entry to the log below. The "Take" and "Don't take" lines are what Claude follows.

## How Claude uses these (see SKILL.md §8)

Extract principles → translate into Hermes Wraps tokens, type, motifs and message order → change anything that would make the result recognizable as the reference → state briefly which principles were used.

**Take (principles):** layout rhythm, whitespace, density, type contrast, image cropping and treatment, how proof and CTAs are sequenced, interaction tone, overall polish.

**Don't take (gadgets):** signature widgets, unique interactions or animations, illustration or icon styles, exact hero compositions, copy and headline structures, brand colors, logos, photos, or any asset.

## Reference log

Copy this block for each screenshot.

```
### NN - short name
File: NN-short-name.png

What the client likes: (in the client's words if possible)

Don't take: (distinctive elements to avoid)
Applies to: (Home hero / Work grid / Consultation page / any page)
```
