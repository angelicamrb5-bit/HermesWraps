# Hermes Wraps — project guardrails

Client: Hermes Wraps (vehicle wraps, signs, commercial graphics — Tampa Bay, FL).
Goal of the website: win **medium to large US companies** as contract clients
(fleet managers, marketing, procurement). Young brand, 8+ years of experience:
confident, precise, premium — never flashy.

## Color — non-negotiable
- The palette lives in `brand/tokens.css`, generated by `brand/tools/build_brand_guide.py`.
  The full guide is `brand/hermes-wraps-color-guide.pdf`. Read it before any design work.
- Use only `--hw-*` variables (prefer the role tokens). Never introduce a new hex value or hue.
  To change a color, edit the palette in the build script and re-run it.
- 60/30/10: ~60% ivory/stone, ~30% burgundy/midnight, ~10% gold.
- Never Wraps Gold (#C9A477) as text on light backgrounds — use `--hw-gold-text`.
- Copper (#C7755E) is decorative linework only.
- All text pairs must meet WCAG AA (4.5:1; 3:1 for 24px+ text).
- Logo goes on midnight, burgundy, or a dark plate — never directly on busy photos.
